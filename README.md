# Sales-Overview-Dashboard

Designed and developed an end-to-end Sales Overview Dashboard in Power BI, consolidating multi-regional sales data to provide stakeholders with actionable, real-time insights into regional performance and YoY growth metrics.

Implemented advanced data visualization techniques, including conditional formatting for KPI tables and interactive geospatial mapping for regional analysis, enhancing data storytelling and decision-making for executive teams.

Engineered a streamlined, user-centric dashboard layout by optimizing data groupings and applying professional design principles to track key business drivers (Sales, Profit, Quantity) across multiple fiscal years.
